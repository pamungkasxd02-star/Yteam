# YTEAM Reporting Skill

Use this playbook only after the validation gates pass. Reports and PoCs are
written in English; evidence is redacted and stored on the data drive.

## Procedure

1. State what the attacker can do now and what concrete asset is affected.
2. Include the exact request, response semantics, prerequisites, and scope.
3. Separate confirmed facts, negative controls, assumptions, and non-claims.
4. Select severity from demonstrated impact, not theoretical escalation.
5. Mark the result `PACK`, `CAND`, `MID`, `BLOCKED`, or `0`; never auto-submit.
